# AI marketplaces

## Install for Claude Code

```sh
claude plugin marketplace add vndly/marketplace
claude plugin install common@vndly
```

## Install for Codex

```sh
codex plugin marketplace add vndly/marketplace
codex plugin add common@vndly
```

## Install for Antigravity CLI

```sh
agy plugin install https://github.com/vndly/marketplace/tree/main/plugins/antigravity
```
